# Threat model

STRIDE tables, data-flow diagrams, and attack trees (Mermaid) for S1–S6.

Target state: generated from `@ov1/catalog` by `pnpm docs:threats` (backlog task
`threat-docs-gen`), so the threat model can never disagree with the code. Hand-written analysis that
can't be generated (narrative, assumptions, trust boundaries) goes in `narrative.md`.
